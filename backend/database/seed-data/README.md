# CoJ-MIP Seed Data

Placeholder fixtures used by the `cojmip:repository-seed` artisan command to
prove the JSON-first repository plumbing (Phase 2).

- `organisations.json` — example `CoJOrganisation` rows
- `articles.json` — example article rows
- `sources.json` — example source-trust classifications

## IMPORTANT

These entries are **synthetic placeholders**. All names, URLs and content
are fabricated example data with no relation to any real City of
Johannesburg source or organisation.

They will be **replaced by the curated CoJ dataset** in Phase 3. Do not use
these fixtures to draw any real-world conclusions about CoJ entities.
